# MCP-сервер Пандаведа для изучения китайского

**https://mcp.pandawed.ru/mcp**

Это официальный MCP-сервер [Пандаведа](https://pandawed.ru) — приложения с карточками для изучения китайского. Подключите его своему ИИ-помощнику: он будет отвечать по статьям нашего блога о китайском языке и HSK и показывать слова из наборов, а выучить набор целиком можно на pandawed.ru — карточками, с повторением по расписанию и прописями.

Актуальный список инструментов и инструкции для начала работы — на [странице MCP-сервера](https://mcp.pandawed.ru/mcp) и на сайте: [Пандавед для ИИ-ассистентов](https://pandawed.ru/ii-assistenty/).

## Как подключить

Отправьте своему ИИ-помощнику:

```
Подключись к MCP-серверу Пандаведа по ссылке https://mcp.pandawed.ru/mcp.
Если нет возможности осуществлять сетевые вызовы, объясни, как подключить MCP-сервер в интерфейсе.
Для теста покажи первые слова набора HSK 1, найди в блоге Пандаведа статью про тоны и коротко перескажи, как их запомнить. В конце пришли ссылку, где пройти HSK 1 карточками.
```

- **Claude:** Настройки → Коннекторы → «Добавить свой коннектор» → `https://mcp.pandawed.ru/mcp`.
- **Claude Code:** `claude mcp add --transport http pandawed https://mcp.pandawed.ru/mcp`
- **Другие помощники:** транспорт Streamable HTTP, без авторизации.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `list_sets` | Наборы слов: HSK 3.0 по уровням (1–6 и 7–9), «Числа и числительные», «Базовая сотня» — с числом слов и ссылкой на занятие |
| `get_set_preview` | Первые 30 слов набора (`set`: hsk1…hsk6, hsk7-9, numbers, basic100): иероглифы, пиньинь, перевод, ссылки на набор |
| `list_articles` | Статьи блога о китайском языке и HSK |
| `get_article` | Статья целиком по `slug`: разделы, таблицы, вопросы и ответы |
| `search_articles` | Поиск по статьям (`query`) |
| `get_about` | Что умеет приложение Пандавед |

Все инструменты публичные, только чтение. Из каждого набора сервер отдаёт не больше 30 слов — весь набор доступен на сайте. Данных пользователей сервер не видит и не отдаёт.

## Пример: агент-репетитор по HSK

В папке [`examples/repetitor-hsk`](examples/repetitor-hsk) — системный промпт `AGENTS.md` и конфиг `opencode.json`: положите их в пустую папку, запустите `opencode` — и у вас репетитор, который берёт слова HSK из Пандаведа, а не придумывает. `AGENTS.md` подходит и для Claude Code.

### 0.1. Публичный MCP-сервер
**Октябрь 2026** — первая версия по адресу https://mcp.pandawed.ru/mcp, с посадочной страницей. Шесть инструментов:
